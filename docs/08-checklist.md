# 08. Чек-лист, анти-паттерны, Definition of Done

Пройди этот список перед тем, как сообщать, что работа готова. Каждый пункт проверяем.

## 1. Definition of Done

**Иерархия**
- [ ] Стекло только в слое навигации/управления и в оверлеях. Карточки, ячейки, фон экрана — не стекло.
- [ ] Нет стекла на стекле: элементы внутри стеклянной панели плоские; группы действий — одна поверхность.
- [ ] Контент доходит до краёв и прокручивается под стеклом; вместо разделителей под барами — scroll edge effect.
- [ ] На экране 1–3 стеклянных острова (и не больше бюджета поверхностей).

**Материал**
- [ ] Все значения — из токенов (blur, saturation, fill, rim, тени, радиусы, пружины). Никаких «на глаз» чисел в коде компонентов.
- [ ] Есть все слои: backdrop (blur + saturation), fill, направленный rim, sheen, тень, свечение касания.
- [ ] Вариант выбран по правилам: regular по умолчанию, clear только над медиа (с затемнением при ярком фоне), thick для меню/sheets, tint/prominent — не больше одного-двух на экран.
- [ ] Светлый/тёмный вид стекла следует теме и (для небольших элементов) контенту под ним.
- [ ] На Apple 26+ использован нативный Liquid Glass, а не имитация.

**Геометрия**
- [ ] Кнопки, бары, поля — капсулы; вложенные скругления концентричны (`r_parent − inset`).
- [ ] Плавающие отступы от краёв; размеры касания платформы соблюдены.

**Движение**
- [ ] Все физические анимации — пружины из токенов; прерываемые, сохраняют скорость.
- [ ] Нажатие: набухание + свечение из точки касания + упругий возврат.
- [ ] Индикатор выбора — капля с двумя краями (lead/trail); меню и поповеры морфятся из источника.
- [ ] Анимируются только transform/opacity (или эквиваленты композитора).

**Производительность**
- [ ] Реализованы уровни T0/T1/(T2)/(T3), уровень определяется по возможностям устройства и может понижаться при просадках.
- [ ] Не анимируется радиус размытия; карты/маски кэшируются; стекло скрытых элементов не рисуется.
- [ ] Проверено на самом слабом целевом устройстве: скролл под барами, открытие меню и шторки — без устойчивых просадок.

**Доступность**
- [ ] Reduce Transparency → solid; Increase Contrast → solid + контрастный контур; forced colors → системные цвета; Reduce Motion → без отскоков и «желе».
- [ ] Контраст текста ≥ 4.5:1 на худшем реальном фоне; фокус виден; клавиатура и экранные читалки работают.

**Проверка глазами**
- [ ] Скриншоты: светлая и тёмная тема × фон белый / чёрный / пёстрый × T0 / T1 / T2. Над белым стекло почти белое с тенью, над чёрным — тёмное с ярким контуром, над пёстрым — насыщенно просвечивает.

## 2. Анти-паттерны

| Плохо | Правильно |
|---|---|
| Сильное размытие σ 30–40, молочная заливка 40 % | σ 10 (regular) / 2 (clear), заливка ≈ 20 %, насыщенность 1.8 |
| Равномерная белая рамка 1 px | Направленный rim-градиент (135°) + sheen, в шейдерах — `dot(n, L)` |
| Стеклянные карточки в списке | Непрозрачные карточки; стекло — только бары и кнопки над ними |
| Каждая кнопка тулбара — своё стекло | Одна стеклянная капсула-группа с плоскими кнопками |
| Сплошной фон навбара + разделитель | Острова стекла + scroll edge effect |
| Нажатие уменьшает кнопку (scale 0.95) | Нажатие набухает (до 1.12) и светится из точки касания |
| `transition: all 300ms ease-in-out` | Пружины из токенов, прерываемые, с сохранением скорости |
| Меню появляется fade/scale из центра | Меню морфится из кнопки-источника |
| Анимация `backdrop-filter: blur(0 → 20px)` | Анимация `opacity`/`transform` стеклянного слоя |
| Fade-in модалки через `opacity` родителя (web) | Прозрачность анимируется у самого стеклянного элемента (Backdrop Root) |
| Внешняя тень на элементе с `backdrop-filter: url()` (Chromium) | Backdrop в `::before`, тень на элементе |
| SF Pro / SF Symbols, встроенные в Android/Windows/web-сборку | Системный шрифт / Inter; Lucide / Phosphor / Material Symbols Rounded |
| Tint на всех барах | Tint — одно главное действие или выбранное состояние |
| Clear-стекло над белым текстом | Regular, или clear + затемняющий слой |
| Игнор Reduce Transparency / Motion | Tier T0, пружины с ζ = 1 |
| Имитация стекла поверх нативного на iOS 26 (`.ultraThinMaterial` + обводка) | `.glassEffect()`, `.buttonStyle(.glass)`, `GlassEffectContainer` |
| Выдуманные API «для правдоподобия» | Только проверенные API; если сомневаешься — сверься с документацией SDK и пометь в отчёте |

## 3. Что сообщить пользователю по завершении

1. Какой уровень (T0–T3) получает какой класс устройств и как это определяется.
2. Какие компоненты сделаны и где лежит общий слой токенов/стиля.
3. Какие части эффекта на этой платформе приближённые (например: «рефракция только в Chromium», «слияние капель — имитация перетеканием»).
4. Как проверено: скриншоты (какие фоны/темы), профилирование (устройство, результат).
5. Какие пункты чек-листа не выполнены и почему.
