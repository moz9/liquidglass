# 04. Компоненты

Спецификации платформенно-независимы. Размеры — в px/pt/dp (1×), токены — из [02-tokens.md](02-tokens.md). Реализация в вебе — классы из [`reference/web/liquid-glass.css`](../reference/web/liquid-glass.css); в скобках указан класс.

Общее для всех стеклянных компонентов:
- состояния: *rest*, *hover* (только указатель: glow 35 %), *pressed* (набухание + glow 100 % из точки касания), *focus-visible* (кольцо 2 px accent, отступ 2 px), *disabled* (контент 30 % непрозрачности, без glow и набухания);
- контент внутри стекла плоский: никакого собственного backdrop у вложенных элементов;
- жесты и клавиатура платформы работают как у нативного аналога.

---

## Кнопка (`.lg .lg-btn .lg-interactive`)

| | |
|---|---|
| Форма | capsule; только иконка — круг |
| Высота | 44 touch · 36/28 десктоп · 52 для главного действия |
| Отступы | 18 по горизонтали; иконка 20 + gap 6 |
| Материал | regular; одно главное действие — prominent; поверх медиа — clear |
| Текст | 15 / 600, −0.01em |
| Нажатие | scale → `1 + 8/maxSide` (≤ 1.12) пружиной `press`, свечение из точки касания; при перетаскивании пальца — лёгкое растяжение и смещение к пальцу; отпускание — `release` |

## Остров тулбара / группа (`.lg .lg-group` + `.lg-item`)

Несколько действий в одной стеклянной капсуле. Это **одна** поверхность: элементы внутри — прозрачные кнопки с hover-подложкой `hover` и pressed-подложкой `indicator`.

| | |
|---|---|
| Padding | 4, gap 2 |
| Элемент | 36 × ≥ 36, capsule, иконка 20 или текст 15/600 |
| Группировка | по смыслу: навигация слева, действия справа; между группами зазор 8 (отдельные острова) |
| Разделители | не нужны: группы разделяет воздух; внутри группы при необходимости — `ToolbarSpacer`-подобный зазор 8 |

## Панель навигации (navigation bar)

- Нет сплошного фона и нижнего разделителя. Кнопки «назад» и действия — стеклянные острова, заголовок — текст прямо на контенте (large title 34/700 слева, при прокрутке — inline title 17/600 по центру).
- Под островами — scroll edge effect (`.lg-scroll-edge--top`): контент растворяется размытием и градиентом высотой 96.
- Острова адаптивны: светлый/тёмный вид по контенту под ними.

## Таб-бар (`.lg .lg-tabbar` + `.lg-tab` + `.lg-indicator`)

| | |
|---|---|
| Положение | плавает по центру снизу: 12 над safe area, по бокам ≥ 16 |
| Размер | высота 62, padding 4, вкладки ≥ 68 шириной, 3–5 вкладок |
| Вкладка | иконка 24 + подпись 10/600, gap 3; выбранная — цвет accent |
| Индикатор | капсула `indicator` внутри бара (заливка, не второй backdrop) |
| Поиск | отдельная круглая стеклянная кнопка 62 справа от бара (у Apple — вкладка с `role: .search`) |
| Минимизация | при прокрутке вниз бар сжимается до выбранной вкладки (только иконка, ширина ≈ 62), при прокрутке вверх — разворачивается; пружина `smooth` |
| Жидкий индикатор | см. ниже и [05-motion.md](05-motion.md#5-индикатор-выбора-капля) |

**Индикатор выбора.** Два края — две пружины: передний (`lead`) быстрее заднего (`trail`), поэтому капля вытягивается в сторону движения и схлопывается. Бар можно «тянуть» пальцем: индикатор становится clear-линзой (прозрачнее, яркий контур, ×1.10), следует за пальцем пружиной `interactive`, при отпускании прилипает к ближайшей вкладке. Клавиатура: ←/→/Home/End, roving tabindex, `role="tablist"`/`tab`, `aria-selected`.

## Сегментированный контрол (`.lg .lg-seg` + `.lg-seg__item`)

Капсула высотой 36 (десктоп 28), padding 3, сегменты ≥ 72, текст 13/600. Индикатор и жесты — как у таб-бара. В контенте (не в тулбаре) допускается нестеклянный вариант: подложка `indicator` на сплошном фоне.

## Переключатель (`.lg-switch`)

| | |
|---|---|
| Размер | 64 × 28, бегунок 38 × 24 (капсула), ход 22 |
| Покой | трек `rgb(120 120 128/.2)` / включено — green; бегунок белый с тенью |
| Нажатие | бегунок становится **clear-линзой**: прозрачный, яркий внутренний контур, лёгкое размытие + насыщенность того, что под ним, ×1.45 по горизонтали / ×1.5 по вертикали, пружина `press` |
| Отпускание | обратно в белый бегунок пружиной `release`; перемещение — `snappy` |
| Перетаскивание | бегунок следует за пальцем по треку (`interactive`), при отпускании — к ближайшему краю |

## Слайдер

Трек 6 высотой (заполненная часть — accent), бегунок-капсула 38 × 24 белый. При нажатии бегунок, как у переключателя, превращается в clear-линзу ×1.4 и **увеличивает** трек под собой (лупа: рефракция с большим `strength` на T2+, на T1 — только контур и прозрачность). Отпускание — `release`. Шаговые слайдеры прилипают к делениям пружиной `snappy` с лёгкой тактильной отдачей.

## Поле поиска (`.lg .lg-search`)

Капсула 44, padding 16, иконка лупы 18 (60 %), текст 17/400, placeholder `secondaryLabel`. На телефоне — внизу экрана (над клавиатурой при фокусе); при фокусе поле перетекает из кнопки поиска таб-бара (морфинг). На десктопе — в тулбаре справа. Фокус: кольцо accent 2 px.

## Меню, поповер, контекстное меню (`.lg .lg-thick .lg-menu`)

| | |
|---|---|
| Материал | thick, тень elevated |
| Радиус | lg (24); пункты — концентрично: `24 − 6 = 18` |
| Размер | ≥ 220 ширина, padding 6, пункт 40 высотой (десктоп 28–32), текст 15/500, иконка 20 слева или справа |
| Появление | **морфинг из кнопки-источника**: одна стеклянная поверхность меняет прямоугольник и радиус пружиной `morph`, источник скрывается, содержимое проявляется на последних ~45 % пути |
| Закрытие | обратный морфинг пружиной `dismiss` (быстрее, без отскока); клик вне, Esc, выбор пункта |
| Доступность | `role="menu"`/`menuitem`, фокус на первый пункт при открытии и возврат на источник при закрытии, стрелки ↑/↓ |

## Sheet / нижняя шторка (`.lg .lg-thick .lg-sheet`)

- Частичная высота (medium detent): стекло thick, отступ 8 от краёв экрана, радиус концентричен углам экрана (≈ 44 на телефоне), тень elevated.
- Полная высота (large detent): прилипает к краям, нижние углы 0, **становится непрозрачным** (solid) — так читается длинный контент.
- Перетаскивание: `interactive`, сверх пределов — rubber band; отпускание к ближайшему detent пружиной `smooth` с учётом скорости.
- Хват (grabber) 36 × 5, `secondaryLabel`. Контент под модальной шторкой затемняется `rgb(0 0 0/.2)` с fade.

## Алерт / диалог

Thick-стекло, радиус xl (32), ширина 270–320 (телефон), padding 20. Заголовок 17/600 **по левому краю**, текст 15/400 по левому краю, кнопки — капсулы на всю ширину или в ряд (главная — prominent). Появление: `bouncy` scale 0.9 → 1 + fade; фон затемняется. Деструктивное действие — красный текст на regular-кнопке.

## Sidebar (планшет, десктоп)

Плавающая стеклянная панель: отступ 8–12 от краёв окна, радиус lg, высота окна минус отступы. Контент окна проходит **под** sidebar до левого края (у Apple — `backgroundExtensionEffect`: крайнее изображение отражённо продолжается под панелью). Выбранный пункт — подложка `indicator`, capsule/concentric. Сворачивание — морфинг в кнопку тулбара.

## Окно десктопного приложения

- Тулбар без сплошного фона: стеклянные группы поверх контента, контент идёт под тулбар, scroll edge effect.
- Радиус окна крупнее обычного (≈ 16–26, где ОС позволяет скруглять окна).
- Фон окна — контент или системный материал окна (Windows: Mica; macOS: нативно). Стекло Liquid Glass — только на плавающих элементах.

## Toast / HUD / уведомление

Капсула или lg-прямоугольник, regular (над тёмным медиа — автоматически dark), появление `bouncy` сверху/снизу со scale 0.9, исчезновение `dismiss` + fade. Не больше одного одновременно.

## Карточки, ячейки, списки — НЕ стекло

Это контент: непрозрачная поверхность (`#FFFFFF` / `#1C1C1E` на фоне `#F2F2F7` / `#000`), радиус 22–26, без backdrop. Если очень хочется «стекла» на карточке — используй *статичную* тонкую обводку и мягкую тень, но не живой backdrop: десятки размытых карточек в скролле — это и не Liquid Glass, и гарантированные просадки FPS.
